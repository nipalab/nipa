# Changelog

## 0.1.0 (unreleased)

- Native VCS plugin `NipaVCSInterface` and the Nipa dock (Phase 1).
- File locks (Phase 2): auto-lock on edit, context menus, toolbar and Inspector badges, Locks tab, commit lock pre-check and opt-in strict read-only mode.
- Conflicts, tags, merges and previews (Phase 3): Godot-aware scene merge, external merge tool, merge/revert banners, tag checkout, History and Image diff tabs.
- Setup and distribution (Phase 4): setup checker with one-click fixes, sidecar warning banner, opt-in FileSystem dock decoration, release zips for Windows, Linux (x86_64, arm64) and macOS.
